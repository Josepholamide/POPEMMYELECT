FOLDER STRUCTURE

OPEN IN VS CODE
1. Download the ZIP and extract it.
2. In VS Code choose File > Open Folder.
3. Select the folder named popemmyelect-site.
4. Open index.html.
5. If Live Server is installed, right-click index.html and choose Open with Live Server.

PHONE
The layout is responsive and includes a working mobile hamburger menu.

QR CODE
The QR button creates a QR code from the current website URL. Do NOT print it for the business card until the website has its final public URL.
